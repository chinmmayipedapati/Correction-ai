# SpeakUp — AI Communication Coach

Practice speaking or type a transcript, receive Gemini coaching, and track saved sessions locally.

## Start locally

Use Node.js 22 or newer. In two terminals, from the project folder:

```powershell
npm install --prefix server
npm start --prefix server
```

```powershell
npm install --prefix client
npm run dev --prefix client
```

Open http://localhost:5173. The backend uses port 3001; the frontend proxies `/api` to it.

The local `server/.env` contains the API configuration and is ignored by Git. On a fresh checkout, copy `server/.env.example` to `server/.env` and set `GEMINI_API_KEY`. `GEMINI_MODEL` is configurable; the current default is `gemini-3.5-flash`. Restart the backend after changing configuration. Keep credentials on the server.

## Practice

1. Open Start Practice, enter a context, and choose a coaching style.
2. Use the microphone in a browser that supports audio recording, or choose text typing mode. Audio is sent to Gemini after Finish & Analyze; transcription and statistics appear after recording.
3. Click Finish & Analyze. If analysis fails, the transcript stays available for retry; the app does not invent scores.
4. Review the eight metrics, suggested opening and closing, and next exercise.
5. Return to the dashboard or Progress to revisit saved sessions.

Feedback assesses transcript content, not vocal tone, pronunciation or body language. Manual-mode elapsed time measures typing time, not actual speaking pace. Filler-word matching is a heuristic and can count legitimate uses of words such as “like.” The camera is a local preview only. Microphone audio is recorded locally using MediaRecorder, then sent through the backend to Gemini when you finish (maximum 12 MB). Audio is retained in memory for retry, and is not saved to localStorage. Transcripts are sent to Gemini when analyzed, and completed reviews are stored in this browser's localStorage. Clearing site data removes saved sessions.

## Verification

```powershell
node --test server/index.test.js client/src/utils/sessionStorage.test.js
npm run lint --prefix client
npm run build --prefix client
```

For an optional real provider check using the configured key (uses API quota):

```powershell
node server/verify-live.cjs
```

`GET /api/health` reports whether a key is configured; it does not authenticate the key. API failures show actionable errors for missing configuration, quota limits, timeouts, and invalid model responses.

## Scope

This is a local, single-user MVP. Browser microphone/camera permission flows and an actual spoken session still require manual verification. Existing reviews generated by the older mock fallback cannot be distinguished reliably from real reviews and are preserved as historical data.

Gemini integration follows the official REST reference: https://ai.google.dev/api/generate-content
